# High IQ Battle

Мобильная игра-викторина для двоих (или больше) — как Kahoot, но с вопросами
по финансам (CFA Level 2 + макро), кино, политике, спорту и не только.
Каждый игрок заходит со своего телефона, вступает в одну комнату по
короткому коду, и оба одновременно отвечают на один и тот же вопрос за 30
секунд.

## Правила начисления очков

- 4 варианта ответа, 30 секунд на вопрос. Порядок вариантов перемешивается
  сервером заново для каждого раунда — правильный ответ не "залипает" на
  одной и той же букве.
- Очко получает **самый быстрый из ответивших правильно**. Если оба выбрали
  правильный вариант — засчитывается тому, кто ответил быстрее (в
  миллисекундах). Если правильно ответил только один — очко его, независимо от
  скорости. Если оба ошиблись — очков в этом раунде нет.
- После каждого вопроса — экран с правильным ответом, объяснением и текущим
  счётом. Хост нажимает кнопку **«Дальше»**, когда оба готовы двигаться к
  следующему вопросу (игра не переключается сама по таймеру).
- Перед началом раунда хост настраивает темы и количество вопросов, затем
  подтверждает кнопкой **«Поехали!»** на отдельном экране — старт не
  срабатывает случайно при настройке.

## Выбор тем

Темы показаны вертикальным цветным списком (листается вниз). Отдельные темы
CFA Level 2 (11 штук) объединены под одной строкой **«CFA»** — нажатие на неё
открывает список CFA-тем для выбора, чтобы не засорять главный список.
Остальные категории (сериалы, политика, спорт и т.д.) выбираются сразу на
главном экране.

## Структура репозитория

```
server/       Node.js + Socket.io backend — комнаты, таймер, подсчёт очков
app/          Мобильное приложение на Expo (React Native) — iOS и Android
questions/    Банк вопросов (JSON), 17 тем, 1200 вопросов
```

### Как дорастить банк до 2000 вопросов

Формат описан в `questions/SCHEMA.md`. Чтобы добавить вопросы:

1. Допишите объекты в существующий файл темы (или создайте новый файл) той же
   формы: `id`, `topic`, `subtopic`, `difficulty`, `question`, `options[4]`,
   `correctIndex`, `explanation`.
2. Если добавляете новый файл — впишите его имя в `TOPIC_FILES` в
   `server/src/questions.js`.
3. Сервер сам подхватит вопросы при следующем запуске — база вопросов не
   привязана к коду игры.

Дальше можно расширять пачками (например, попросить меня сгенерировать ещё
N вопросов по конкретной теме) — вся инфраструктура уже рассчитана на любое
количество вопросов.

## Первоначальная установка (один раз)

Вместо повторного скачивания ZIP-архива при каждом обновлении удобнее один
раз подключить папку к GitHub через `git` — дальше обновление сводится к
одной команде `git pull`. См. раздел «Как обновлять игру» ниже.

```bash
git clone -b claude/relaxed-thompson-97cm2i https://github.com/beibars-cyberpro/beibars.git
cd beibars
```

## Как запустить и сыграть вдвоём

**Быстрый способ (Mac):** в папках `server/` и `app/` есть файлы
`start-server.command` и `start-app.command` — просто **дважды кликните**
по ним в Finder, как по обычной программе, без набора команд в терминале
(macOS сам откроет окно терминала и выполнит нужные шаги). При первом
запуске `start-app.command` сам создаст `config.js` из примера и попросит
вписать туда IP — после этого запустите его повторно.

Ниже — то же самое вручную, через команды.

### 1. Backend

```bash
cd server
npm install
npm start
```

Сервер поднимется на `http://localhost:3001`. Для игры на **одном Wi-Fi**
достаточно локального запуска — узнайте IP компьютера в локальной сети:

- Mac: `ipconfig getifaddr en0`
- Windows: `ipconfig` → IPv4-адрес

### 2. Приложение (Expo)

```bash
cd app
npm install
```

Скопируйте `app/src/config.example.js` в `app/src/config.js` (один раз) и
впишите там IP компьютера из предыдущего шага:

```bash
cp src/config.example.js src/config.js
```

```js
export const SERVER_URL = 'http://192.168.1.23:3001';
```

`config.js` специально исключён из git (см. `.gitignore`) — он не будет
затираться при будущих `git pull`, ваш IP-адрес останется на месте.

Затем:

```bash
npx expo start
```

Установите **Expo Go** на оба телефона (App Store / Google Play), оба
телефона должны быть в той же Wi-Fi сети, что и компьютер. Отсканируйте QR-код
из терминала камерой телефона (iOS) или приложением Expo Go (Android) — на
обоих телефонах откроется одно и то же приложение.

Один игрок создаёт комнату («Создать комнату»), получает 4-значный код и
делится им со вторым игроком — тот вводит код во вкладке «Войти по коду».
Хост выбирает количество вопросов и (опционально) темы, жмёт «Начать игру».

### 3. Игра через интернет, с друзьями, без привязки к вашему компьютеру

Чтобы сервер работал постоянно и друзья могли подключаться из любой сети
(не только по одному Wi-Fi), разверните `server/` на бесплатном хостинге.
В репозитории уже есть готовый конфиг `render.yaml` для сервиса
[Render](https://render.com):

1. Зайдите на render.com, зарегистрируйтесь (можно через GitHub-аккаунт).
2. **New** → **Blueprint** → выберите репозиторий `beibars-cyberpro/beibars`
   → Render сам найдёт `render.yaml` и предложит создать сервис
   `high-iq-battle-server` на бесплатном плане — подтвердите.
3. Через пару минут деплой завершится, Render выдаст адрес вида
   `https://high-iq-battle-server.onrender.com`.
4. Впишите этот адрес в `app/src/config.js` вместо локального IP:
   ```js
   export const SERVER_URL = 'https://high-iq-battle-server.onrender.com';
   ```
5. Перезапустите `start-app.command`.

Теперь ваш компьютер вообще не нужен держать включённым — сервер работает
в облаке 24/7. Друзья с установленным Expo Go могут присоединиться к игре
из любого места: хост создаёт комнату, жмёт на код комнаты — откроется
системное меню «Поделиться» (можно отправить код в любой мессенджер),
друг вводит этот код во вкладке «Войти по коду».

(Бесплатный план Render «засыпает» после 15 минут без запросов и ~30–60
секунд «просыпается» при первом подключении — для казуальной игры с
друзьями это не проблема, просто первый вопрос может прийти с небольшой
задержкой.)

## Игра в Telegram (Mini App)

Игру можно открывать прямо внутри Telegram, без App Store и без Expo Go —
как Telegram Mini App. Технически это та же игра, собранная в веб-версию
(`npm run build:web` в папке `app` — собирает в `server/public`, который
сервер сам раздаёт по корневому адресу `/`). При деплое на Render это уже
настроено: `render.yaml` сам пересобирает веб-версию при каждом деплое.

Чтобы подключить это к Telegram (это шаг, который нужно сделать тебе лично
— через твой Telegram-аккаунт):

1. Напиши **@BotFather** в Telegram.
2. `/newbot` — если ещё нет бота для игры (придумай имя и username,
   например `HighIQBattleBot`).
3. `/newapp` — выбери только что созданного бота, следуй подсказкам:
   название, описание, картинку (можно любую квадратную, 640×360 для
   превью необязательно точно соблюдать) и **Web App URL** — вставь туда
   адрес с Render, например `https://high-iq-battle-server.onrender.com`.
4. BotFather выдаст короткую ссылку вида `t.me/HighIQBattleBot/app` —
   открой её в Telegram, нажми «Запустить» — откроется игра прямо внутри
   мессенджера.

Дальше делиться игрой — это просто переслать эту ссылку другу в любом
чате Telegram. Счёт и темы работают точно так же, как и в мобильном
приложении — это один и тот же сервер.

## Как сделать полноценное приложение для App Store / Google Play

Это уже следующий, более серьёзный шаг — не бесплатный и не быстрый, но
вполне реальный. Коротко, что для него понадобится:

- **Google Play (Android)** — аккаунт разработчика Google Play, разовый
  платёж $25, сборка через `eas build --platform android`, несколько дней
  на первую модерацию. Обычно проще и быстрее, чем Apple.
- **App Store (iOS)** — членство в Apple Developer Program, $99/год (нужен
  Apple ID и банковская карта), сборка через `eas build --platform ios`,
  публикация через App Store Connect, модерация Apple (обычно 1–3 дня,
  иногда с запросом уточнений).

Я могу подготовить техническую часть (иконку, конфиг сборки EAS, тексты
для карточки приложения в сторе), но сами аккаунты разработчика и оплату
нужно оформить вам лично — это ваш Apple ID / Google-аккаунт, я не могу
сделать это за вас. Скажите, с какой платформы хотите начать (обычно
логичнее с Google Play — дешевле и быстрее), и я подготовлю всё, что
можно сделать до создания аккаунта.

## Как обновлять игру

Если папка была склонирована через `git clone` (см. выше), обновление после
того, как я внёс изменения, — это одна команда:

```bash
cd beibars
git pull
```

`config.js` при этом не тронется (он в `.gitignore`) — IP-адрес сервера
останется как был. Если менялись зависимости (`package.json`) — на это
момент я предупрежу отдельно, и тогда нужно один раз выполнить `npm install`
заново в соответствующей папке (`server` или `app`). После `git pull` просто
перезапустите `npm start` и `npx expo start`, если они были открыты.

Если предпочитаете не набирать команды в терминале — то же самое можно
делать через приложение **GitHub Desktop** (desktop.github.com): один раз
клонировать репозиторий кнопкой «Clone», а дальше при каждом обновлении
нажимать кнопку **«Pull origin»**.
